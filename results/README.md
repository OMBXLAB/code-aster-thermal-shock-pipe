# Résultats

Ce dossier accueillera uniquement les résultats effectivement obtenus après
exécution et vérification du modèle :

- cartes de température ;
- profils de température dans l’épaisseur ;
- cartes de contraintes ;
- courbes temporelles ;
- études de convergence ;
- comparaisons analytiques.

Chaque figure devra préciser les unités, l’instant considéré, le maillage et
les hypothèses nécessaires à son interprétation.
